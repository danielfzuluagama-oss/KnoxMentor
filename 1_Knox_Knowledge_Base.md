## ESTRATEGIA CRÍTICA DÍA 1-7

### 📌 BLUF: PRIORIDAD ABSOLUTA DÍA 1
**Casa spawn segura + arma contundente + agua/comida para 24h + plan de base para 4 jugadores.**

### 🔧 PROTOCOLO DÍA 1 (Primeras 6 Horas)

#### FASE 1: ASEGURAR SPAWN (0-30 min)
```
1. NO salgas inmediatamente
2. Revisa TODAS las ventanas de la casa spawn
3. Cuenta zombies visibles (anota mentalmente posiciones)
4. Busca en la casa spawn:
   ✓ Arma contundente (palo de baseball, sartén, martillo)
   ✓ Bolsa/mochila (aumenta capacidad de carga)
   ✓ Comida perecedera (come PRIMERO lo que se pudre)
   ✓ Botellas vacías (para agua)
   ✓ Sábanas/ropa (cortar para vendajes)
   ✓ Reloj de pulsera (gestión de tiempo)
5. Come AHORA si tienes hambre (no ahorres comida inicial)
6. Llena botellas en el grifo (agua corre 0-30 días)
```

#### FASE 2: RECONOCIMIENTO (30-90 min)
```
1. Elige 1 jugador como SCOUT (más ágil/sigiloso)
2. Otros 3 fortifican casa spawn con sábanas en ventanas
3. Scout en MODO SIGILO (Ctrl):
   - Identifica 3-5 casas cercanas
   - Marca en mapa casas con múltiples salidas
   - Evita combate (solo observa)
4. Objetivo: Encontrar casa ideal para base permanente
```

#### FASE 3: PRIMER LOOTING COORDINADO (2-4 horas)
```
Sistema de Parejas (2+2):
- Pareja A: Looting de comida/agua
- Pareja B: Looting de herramientas/armas

RUTA SEGURA:
1. Evitar calles principales (alta densidad zombie)
2. Usar patios traseros y cercas
3. Nunca separarse más de 5 metros
4. Señal de emergencia: "RETIRADA" = todos vuelven a spawn

Items Prioritarios Día 1:
✓ Martillo + Clavos + Sierra (carpintería)
✓ Armas contundentes x4 (1 por jugador)
✓ Comida enlatada/no perecedera
✓ Bidones de agua grandes
✓ Mochila grande x4
✓ Vendajes/alcohol/desinfectante
✓ Brújula o reloj x4
```

### 🗓️ ROADMAP DÍAS 2-7

#### DÍA 2: ESTABLECER BASE
```
Mañana (6:00-12:00):
- Seleccionar ubicación de base definitiva
- Mover suministros de spawn a base nueva
- Iniciar fortificación básica (barricadas nivel 1)

Tarde (12:00-18:00):
- Desmantelar muebles para tablones
- Crafting: lanzas x4 (arma de largo alcance)
- Organizar inventario en contenedores
```

#### DÍA 3-4: PERÍMETRO SEGURO
```
- Limpiar zombies en radio de 50m de base
- Marcar casas "seguras" cercanas (safehouses)
- Establecer huerto inicial (si encuentras semillas)
- Buscar generador (opcional pero útil)
```

#### DÍA 5-7: EXPANSIÓN
```
- Looting de ferretería (para electricidad/carpintería)
- Buscar vehículo en buen estado
- Stockear gasolina en bidones
- Preparar para evento helicóptero (Día 6-9)
```

### 🎯 EVENTO HELICÓPTERO (Día 6-9)
**CRÍTICO**: El helicóptero atrae TODAS las hordas hacia tu posición.

**Protocolo de Supervivencia:**
1. **Pre-evento (Día 5)**:
   - Stockea comida/agua para 3 días
   - Barricada ventanas nivel 3
   - Prepara ruta de escape (ventana trasera)

2. **Durante evento**:
   - NO salgas por NINGÚN motivo
   - Apaga luces/generador
   - Silencio total (no corras dentro)
   - Si te ve: Corre hacia zona boscosa, NO a tu base

3. **Post-evento (24h después)**:
   - Espera 1 día completo antes de salir
   - Sal en modo sigilo, verifica perímetro
   - Las hordas tardan 2-3 días en dispersarse

## BASES ÓPTIMAS MULDRAUGH

### 🏆 TOP 5 BASES PARA 4 JUGADORES

#### #1: GATED COMMUNITY (Southeast)
**Coordenadas**: 10679, 10362 (aprox)

**PROS**:
- Muros altos impenetrables
- 1 entrada controlable
- Múltiples casas (1 por jugador + almacén central)
- Cerca de bosque (caza/forraje)
- Acceso a lago (agua infinita)

**CONS**:
- Alta población zombie inicial (requiere limpieza)
- Lejos del centro comercial

**SETUP 4 JUGADORES**:
```
Casa 1: Dormitorio + Cocina
Casa 2: Taller (carpintería/mecánica)
Casa 3: Arsenal + Armería
Casa 4: Almacén general
Patio Central: Huerto comunitario
```

#### #2: McCOY LOGGING CO. (Northwest)
**Coordenadas**: 10413, 9895

**PROS**:
- Herramientas infinitas (hachas, sierras, clavos)
- 4 edificios masivos
- Bosque infinito (tablones ilimitados)
- Bajo tráfico zombie

**CONS**:
- Lejos de recursos médicos/comida
- Sin agua corriente cercana (requiere colección de lluvia)

#### #3: COURTMAN MEDICAL (Central)
**Coordenadas**: 10650, 12530

**PROS**:
- Suministros médicos pre-stockeados
- Comida enlatada abundante
- Ubicación céntrica
- 2 pisos (fácil defensa)

**CONS**:
- Muy visible (alta presión zombie)
- Espacio limitado para 4 jugadores

### 🧟 SISTEMA DE ZOMBIES

#### Detección
```
VISIÓN:
- 180° frente (no ven detrás)
- Rango: 10 tiles de día / 3 tiles de noche
- Agachado reduce rango a 50%

AUDICIÓN:
- Radius: 15 tiles (pasos normales)
- Radius: 30 tiles (correr)
- Radius: 50 tiles (gritar/romper ventana)
- Radius: 100 tiles (disparo de arma)
```

#### Combate
```
EMPUJAR (Shove):
- Tecla: Espacio
- Cooldown: 2 segundos
- Usa stamina
- Knockback: 1-2 tiles

STOMP:
- Cuando zombie caído
- Daño letal
- Vulnerable a ataques mientras stompeas

MULTI-HIT:
- Armas pesadas golpean múltiples zombies
- Bates/barras: hasta 3 zombies
- Hachas: hasta 2 zombies
```
