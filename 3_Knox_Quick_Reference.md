## 🔧 TROUBLESHOOTING RÁPIDO

### PROBLEMAS COMUNES DÍA 1-7

| Problema | Causa | Solución Inmediata |
|----------|-------|-------------------|
| **"Constantemente sediento"** | No llevas agua suficiente | Llena 2 botellas por jugador |
| **"Zombies aparecen de la nada"** | Migración + ruido | Reduce ruido, evita disparar |
| **"Arma se rompe muy rápido"** | Baja durabilidad | Usa lanzas (reparables) |
| **"Me perdí"** | No marcas en mapa | Usa objetivos únicos como landmarks |
| **"Comida se pudre"** | Comiste no-perecedera primero | Come perecederos PRIMERO |
| **"No encuentro X item"** | Buscas en ubicaciones equivocadas | Consulta tabla de loot |
| **"Infectado (no zombie)"** | Comida podrida o herida sucia | Reposo 12h + antibióticos |

## 🏆 PRIORIDADES POR FASE

### EARLY GAME (Día 1-7)
```
1. Supervivencia inmediata (agua, comida, arma)
2. Base temporal segura
3. Limpieza perímetro
4. Preparación evento helicóptero
```

### MID GAME (Día 8-30)
```
1. Base permanente fortificada
2. Agricultura inicial
3. Vehículo funcional
4. Sistema de agua post-corte
```

### LATE GAME (Día 31-90)
```
1. Agricultura avanzada
2. Múltiples vehículos
3. Safehouses secundarias
4. Sistema de rotación de suministros
```
