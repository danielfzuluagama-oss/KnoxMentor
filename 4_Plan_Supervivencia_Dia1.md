## ⏱️ PLAN DE ACCIÓN - PRIMERAS 6 HORAS

### HORA 1: CONSOLIDACIÓN Y ROLES (Inmediatamente)

#### PASO 1: Reunión de Equipo (5 minutos)
```
UBICACIÓN: Casa spawn del host (o punto de encuentro acordado)

AGENDA:
1. Confirmar que todos están conectados
2. Revisar inventarios iniciales (compartir info)
3. Asignar roles TEMPORALES
```

#### PASO 2: Asignación de Roles (10 minutos)

**ROL A: LÍDER/COMBATIENTE**
- Jugador con mejor reacción/experiencia
- Tomar decisiones en emergencias
- Proteger al grupo durante looting

**ROL B: EXPLORADOR/LOGÍSTICO**
- Jugador con mejor sentido de orientación
- Mapear zona cercana
- Identificar ubicación de base candidata

**ROL C: RECOLECTOR/MÉDICO**
- Jugador más paciente/metódico
- Looting de comida/agua/medicina
- Organizar inventarios

**ROL D: CONSTRUCTOR**
- Jugador interesado en crafteo
- Buscar herramientas
- Iniciar fortificación de casa spawn

#### PASO 3: Asegurar Casa Spawn (15 minutos)

**TODOS PARTICIPAN:**

1. **Revisar ventanas** (2 min)
   - Contar zombies visibles
   - Marcar ventanas rotas

2. **Looting interno** (5 min)
   ```
   Prioridad en casa spawn:
   □ Cuchillo de cocina
   □ Sartén/Rolling pin (arma contundente)
   □ Mochila/bolsa
   □ Comida perecedera (comer AHORA si tienen hambre)
   □ Botellas vacías (llenar en grifo)
   □ Sábanas/cortinas (cortar para vendajes)
   □ Encendedor/fósforos
   ```

3. **Fortalecer entradas** (8 min)
   - Constructor: Barricada puerta principal con muebles
   - Otros: Colgar sábanas en TODAS las ventanas
   - Verificar puerta trasera (debe tener salida despejada)

---

### HORA 2: RECONOCIMIENTO Y PRIMERA EXPANSIÓN

#### PASO 4: Exploración en Parejas (30 minutos)

**PAREJA 1 (Líder + Explorador):**
```
MISIÓN: Reconocimiento táctico
RUTA: Caminar 100m en cada dirección cardinal desde spawn
OBJETIVO: Identificar 3 casas candidatas para base

CHECKLIST:
□ Marcar casas con múltiples salidas
□ Anotar concentraciones de zombies
□ Identificar tiendas/recursos cercanos
□ Buscar vehículos (anotar ubicación, no tocar aún)

REGLA CRÍTICA: 
- Modo sigilo (Ctrl) permanente
- Si ven 3+ zombies: RODEAR, no enfrentar
- Distancia máxima entre ambos: 5 metros
```

**PAREJA 2 (Recolector + Constructor):**
```
MISIÓN: Looting de emergencia
RUTA: Casas adyacentes a spawn (máximo 2 casas)
OBJETIVO: Recursos críticos para 24 horas

PRIORIDAD DE BÚSQUEDA:
1. Armas contundentes (bate, crowbar, martillo)
2. Mochilas grandes
3. Comida (prioridad latas)
4. Agua embotellada
5. Herramientas (sierra, martillo, destornillador)
6. Vendajes/alcohol/desinfectante

TÉCNICA LOOTING:
- Constructor rompe ventana trasera (control de ruido)
- Esperar 10 segundos
- Si zombie sale → Recolector golpea desde afuera
- Entrar solo si 100% despejado
```

#### PASO 5: Reagrupación y Evaluación (10 minutos)

**VOLVER A CASA SPAWN:**
```
REUNIÓN:
1. Pareja 1 comparte mapa mental
2. Pareja 2 muestra inventario obtenido
3. DECISIÓN GRUPAL: ¿Casa spawn es viable para base?
   
   SÍ (si tiene):
   ✓ 2+ salidas
   ✓ Ventanas barricadeables
   ✓ Espacio para 4 jugadores
   → Quedarse y fortificar
   
   NO (si falta):
   ✗ Solo 1 salida
   ✗ Muy expuesta
   ✗ Demasiado pequeña
   → Planear mudanza
```

**Explorador:**

**REUNIÓN FINAL DEL DÍA:**

## 🚨 PROTOCOLOS DE EMERGENCIA DÍA 1

### EMERGENCIA 1: "Horda Detectada"

```
SEÑAL: Cualquiera grita "HORDA"

RESPUESTA INMEDIATA:
1. TODOS se agachan (Ctrl)
2. Retroceden lentamente (no correr)
3. Buscan cobertura (cerca, muro, casa)
4. Esperan 2 minutos en silencio
5. Si horda pasa: Continúan misión
6. Si horda se acerca: Corren a casa spawn
```

### EMERGENCIA 2: "Jugador Herido"

```
RESPUESTA:
1. Recolector/Médico va inmediatamente
2. Líder cubre (mata zombies cercanos)
3. Evalúan herida:
   - Rasguño/laceración → Tratar en sitio
   - Mordida → Protocolo mordida
4. Escolta de vuelta a base
```

### EMERGENCIA 3: "Mordida"

```
PROTOCOLO CRÍTICO:

SI JUGADOR ES MORDIDO:
1. Grupo confirma: "¿Seguro que fue mordida?"
2. Si 100% mordida:
   - Jugador tiene 96 horas de vida
   - Continuar ayudando al grupo
3. ANTES DE MORIR (96h después):
   - Transferir TODO el inventario a compañeros
   - Si tienen "Skill Recovery Journal" mod:
     a. Escribir en diario
     b. Anotar ubicación donde dejas el diario
   - Despedida del grupo
4. DESPUÉS DE MUERTE:
   - Nuevo personaje spawns
   - Ir a ubicación del diario (grupo escolta)
   - Leer diario (recuperas 75% XP skills)
   - Continuar con el grupo
```
